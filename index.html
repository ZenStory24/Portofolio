Selama 3 bulan belajar total saya sudah membuat 8 project website. Berikut 3 project terbaik milik saya:

1. Project: Pixel Art Canvas Grid
Di project ini pengguna bisa membuat karyanya dengan lukisan berbentuk piksel-piksel yang ukurannya bisa di sesuaikan dengan kebutuhan pengguna.

Disini logika utamanya ada di pembuatan setiap pikselnya, di javascript saya menggunakan logika Nested Loop/perulangan yang berada di dalam perulangan lainnya. Cara kerjanya: setiap 1 kali perulangan luar (outer loop) berjalan, perulangan dalam (inner loop) akan diselesaikan sepenuhnya.

2. Project: Math Blitz: 15 Seconds Challange
Proyek aplikasi berbasis web ini dirancang khusus sebagai sarana interaktif untuk melatih mental agility (ketangkasan mental) dan kecepatan berpikir melalui tantangan matematika dasar. Bagaimana aplikasi ini bekerja? Aplikasi ini secara otomatis menghasilkan bank soal acak yang terdiri dari operasi penjumlahan, pengurangan, dan perkalian. Pengguna dituntut untuk menyelesaikan total 15 soal di bawah tekanan batas waktu (time constraint) yang dapat disesuaikan sendiri.
Saya juga menggunakan library chart.js untuk membuat diagram lingkaran/pie chart untuk menampilkan data hasil latihan dan user dapat melihatnya secara visual.

3. Project: To Do List
Aplikasi manajemen tugas berbasis web tanpa framework/libraryeksternal untuk menguji pemahaman manipulasi DOM dinamis, event handling, dan pengelolaan state data pada JavaScript.

Fitur Utama:
* Persistent Storage: Data tersimpan otomatis di browser (LocalStorage API) sehingga tidak hilang saat halaman di-refresh.
* Interactive Task Management: Fitur tambah tugas dengan validasi input, serta penanda tugas selesai menggunakan efek garis dicoret (line-through).
* Safe Delete Mode: Fitur toggle mode hapus yang dilengkapi pop-up konfirmasi untuk mencegah penghapusan yang tidak disengaja.
* Dynamic DOM Rendering: Tampilan web dirender secara dinamis dan selalu sinkron dengan data utama (Array of Objects).
